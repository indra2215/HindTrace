# HindTrace — CLI Helper Scripts

Command-line utilities for operating and testing HindTrace.

## Scripts

1. **`run_eval.py`**:
   Runs the full 25 Gold Questions evaluation benchmark from the terminal:
   ```powershell
   python scripts/run_eval.py
   ```

2. **`seed_memory.py`**:
   Pre-seeds Hindsight memory with verified incident resolutions:
   ```powershell
   python scripts/seed_memory.py
   ```

3. **`test_groq.py`**:
   Verifies Groq API key validity and lists available models:
   ```powershell
   python scripts/test_groq.py
   ```
